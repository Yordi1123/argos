# ARGOS Glass — Frontend

Panel de revisión humana y landing pública de ARGOS (React 19 + TypeScript + Vite), servido por nginx en Docker.

```bash
npm ci && npm run dev      # http://localhost:5173 (requiere el backend en :8000)
```
